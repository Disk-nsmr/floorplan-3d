公開管理

間取りごとに、見られる状態（公開中）と見られない状態（公開停止中）を切り替えます。操作できるのは、このサイトの GitHub リポジトリに書き込める人だけです。

管理者として入る

GitHub で作った「アクセストークン」を入力してください。トークンは GitHub へ直接送られ、このサイトには保存されません。

トークンの作り方
  1. GitHub のトークン作成ページを開く（Fine-grained token）
  2. Repository access で「Only select repositories」→ floorplan-3d を選ぶ
  3. Permissions の Repository permissions で Contents を「Read and write」にする
  4. 有効期限を決めて作成し、表示されたトークンをコピーして上に貼り付ける

間取りごとの公開状態

次の図面を完全に削除します。元に戻せません。3Dページ・図面の画像・公開設定がすべて消え、一覧からもなくなります。

    切り替えてからサイトに反映されるまで、1〜2分かかります。今ページを開いている人の画面も、1分以内に自動で切り替わります。

    サイト全体を完全に止めたいとき

    この切り替えは、閲覧者の画面に「公開停止中」を表示する仕組みです。ファイル自体は公開されたままなので、サイトごと止めたい場合は GitHub のPages 設定で「Unpublish site」を選んでください。
